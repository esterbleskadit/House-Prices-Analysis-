# House Prices Analysis

## Overview  
This project analyzes real estate data to understand factors influencing house prices. It explores location, property features, and trends to provide insights for buyers, sellers, and investors.

## Key Questions (Hypotheses)  
- Does location influence property value?  
- Do property features like waterfront and view increase house prices?

## Data  
- Dataset includes house prices, features, locations (zip codes), and more.  
- Some columns have missing values (especially renovation year, waterfront, and view).

## Analysis  
- Geographic distribution of house prices  
- Impact of features like waterfront, view, lot size, and living space  
- Price trends over time

## Visualizations  
- Box plots comparing price vs waterfront and view  
- Distribution of lot sizes and living space by zip code  
- Geographic scatterplots of properties by location and features

## Insights & Advice  
- Location significantly affects house prices, with clusters of high-value homes  
- Waterfront properties and homes with better views tend to have higher prices  
- Bigger lot sizes and living spaces increase property value  
- Buyers should target popular neighborhoods and budget around median prices  
- Sellers should highlight key features to attract buyers  
- Investors should monitor zip codes with growing home sizes and prices
